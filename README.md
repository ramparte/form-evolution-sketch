# Form / Evolution · Perspective Sketch Preview

An independent, lightweight browser prototype of a ceramic form-evolution sketchbook, built October 31, 2026.

Features:
- Vase, Bowl, Chawan, **Teapot**, Pitcher
- Generated teapot body, loop handle, lid, and spout, varied together
- Perspective SVG sketching: elliptical rims, light construction guides, faceting, doubled pencil strokes
- Flat elevation toggle, view angle, complexity, smoothness, and symmetry controls
- Thrown and hand-built modes, 9 evolving variations and backtracking
- Explicit saved favorites only; exploring variants does not register taste
- SVG export, JSON backup/import, local browser persistence

This is a separate preview, not an in-place update of the earlier ChatGPT-site deployment. It does not have access to that deployment's source code, saved designs, or cloud storage.

Open `index.html` in a browser. No build or dependencies.


Controls update: view angle now projects the entire vessel and reveals the elliptical lip/lid, while complexity alters the silhouette's number of profile sections and contour changes. Fixed SVG duplicate attributes so the drawing can be rasterized to a Studio sketch thumbnail.
